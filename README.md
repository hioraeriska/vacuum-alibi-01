One line, at most 200 characters: the excuse a robot vacuum gives for missing a spot.
Entry for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7)
"The Vacuum's Alibi: One Line, 200 Characters".

## The line

> My lidar mapped that corner as a sovereign nation. I do not cross borders without a treaty, and it has not signed one.

Deadpan machine voice, smug about its lidar: the corner is a sovereign nation,
and the vacuum does not cross borders without a treaty — which the corner has
not signed.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It is deterministic
(the same line on every run), uses no network, and reads nothing outside this
repository.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
